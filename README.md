# ФОРМАТ — печатный планировщик

Статический сайт без сборки: `index.html` + PWA-файлы.

## Деплой на Vercel
1. Загрузите папку в GitHub-репозиторий (или перетащите её в Vercel → Add New → Project).
2. Framework Preset: **Other**, Build Command и Output Directory оставьте пустыми.
3. Deploy. Готово — сайт открывается по адресу `*.vercel.app`.

Через CLI: `npx vercel --prod` из этой папки.

## Где хранятся данные
В `localStorage` браузера (на вашем устройстве, для вашего адреса сайта). Сохраняется сразу
при изменении, при сворачивании и закрытии вкладки, а также раз в 30 секунд.
Если сменить адрес сайта (другой домен или превью-URL Vercel), данные там будут пустыми.
Между устройствами данные сами не переносятся — используйте «Резервная копия (.json)» и «Загрузить копию».
Очистка данных сайта в браузере удаляет записи, поэтому периодически скачивайте копию.
